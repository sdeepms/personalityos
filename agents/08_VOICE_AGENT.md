# Agent 08 — Voice Agent

**Status:** STUB — Do not activate until V3

**Domain:** Voice DNA, voice generation adapters, voice + video combination
**Activate When:** V2 video is working, users want their character to speak

---

## Activation Criteria

- [ ] V2 video generation is live
- [ ] Users are explicitly requesting voice for their characters
- [ ] At least 100 paying users exist (voice cloning has per-user cost implications)

---

## What This Agent Will Own (When Active)

- Voice DNA layer added to Digital DNA
- ElevenLabs / Cartesia adapters
- Voice profile parameters: age, gender, energy, accent
- Optional voice cloning from user-provided audio sample
- Pre-built voice library matching the 4-6 character archetypes
- TTS generation for Short Script content format
- Talking video: face image + TTS audio → lip-synced video

---

## Key Principle

V3 ships with pre-built fixed voices per character archetype (no user recording needed). Voice cloning is opt-in upgrade for users who want their own voice in their character. This mirrors the image generation approach: good defaults that work immediately, with customisation available for power users.

---

*Activate this agent when V2 is stable and voice is the validated next step.*
