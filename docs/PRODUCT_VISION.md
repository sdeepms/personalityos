## The Digital DNA

Every character in PersonalityOS has a Digital DNA — a complete, portable record of who that character is.

**Identity Layer**
Name, age, gender, ethnicity, nationality, profession, domain. Who is this character?

**Visual DNA**
Reference images (uploaded by user or AI-generated from parameters). The visual anchor that makes every image look like the same person. Style modifiers, color palette, negative prompts. Stored once. Injected into every generation forever.

**Personality DNA**
Communication style, energy level, tone, teaching approach. How does this character talk? What makes their captions sound like them?

**Prompt DNA**
The assembled master character prompt. Platform-specific formatting rules. Style modifiers per character. Provider-specific adaptations. This is the technical layer that translates identity into generation-ready instructions.

**Future Layers (V3+)**
Voice DNA — voice profile, voice clone references, provider mappings.
Content DNA — brand rules, storytelling frameworks, content preferences.

## The Version Roadmap

### Version 1 — Identity Studio (Now)
**Goal:** Consistent character images + social-ready posts from a chat interface.

Users create characters with Digital DNA. Upload one reference photo. Open the chat studio, type a topic, select a platform (Instagram / LinkedIn / X), get a caption and a consistent image. Every output saves to the asset library. Multiple characters per user.

This is the proof of concept. Does the character stay consistent? Does the caption sound right? Do users come back tomorrow?

### Version 2 — Video Studio
**Goal:** Same identity, now drives video generation.

No new reference uploads. The Visual DNA already stored in V1 is enough. Add video generation model adapters (Kling, Runway, Veo). Add video shortcuts above the chat input. Video assets join the same library.

### Version 2.5 — Content Production Engine
**Goal:** One topic produces a complete content package.

Chat input → script → scene plan → thumbnail concept → captions → visual prompts → all generated assets. The chat is still the interface. The output is richer.

### Version 3 — Voice Layer + Templates
**Goal:** Persistent voice identity. Template marketplace foundations.

Voice DNA added to the identity layer. ElevenLabs / Cartesia adapters. The character now has a consistent speaking voice. Multiple pre-built templates across domains (B2C, B2B, education, coaching) users can buy and start using immediately.

### Version 4 — Marketplace
**Goal:** Identity economy.

Users can publish their characters. Others can buy them. Voice cloning for users who want their own voice in their character. PersonalityOS becomes the marketplace for digital identities — the permanent home of a creator's most valuable digital asset.

## The Open Generative AI Connection

Open Generative AI (github.com/Anil-matcha/Open-Generative-AI, MIT license, 18,500+ stars) solved the generation UI problem — 200+ models, clean polling architecture, good image studio UX.

What it never solved: persistence, identity, ownership. Every generation goes into localStorage. Every session starts fresh. The creator owns nothing.

PersonalityOS is exactly what Open Generative AI is missing. We extract the generation patterns (models.js catalog + muapi.js polling logic), adapt them into our Provider Adapter, and add the entire layer that makes generation meaningful: a persistent identity that drives every prompt.

```
PersonalityOS — Identity Layer (what we build)
        ↓
Provider Adapter — generation routing (our abstraction)
        ↓
Open Gen AI patterns — muapi.js + models.js (what we extract)
        ↓
MuAPI / FAL / Replicate / future providers (what they run)
```
